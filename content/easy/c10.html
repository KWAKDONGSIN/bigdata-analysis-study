코드 손으로 따라가기 훈련 — 예시 보고, 빈칸 채우고, 혼자 풀어요

이 시험은 코드를 만드는 시험이 아니라 코드를 읽고 결과를 고르는 시험이에요. 그래서 필요한 능력은 딱 하나, 코드를 한 줄씩 손으로 따라가며 변수 값을 적어 나가는 힘이에요. 이 장은 그 힘을 아무것도 모르는 상태에서부터 8단계로 키워요.

1단계. print와 변수 — 이름표 상자 값 따라가기

비유 — 실험 노트에 값 적기

시료를 희석할 때마다 노트에 "지금 농도 얼마"를 한 줄씩 고쳐 적잖아요. 코드 따라가기도 똑같아요. 줄이 실행될 때마다 변수 값이 어떻게 바뀌는지 메모장 표에 한 줄씩 적으면, 마지막에 답이 저절로 나와요.

코드 읽기 3원칙
  • 위에서 아래로, 한 줄씩. 컴퓨터는 적힌 순서대로만 일해요. 건너뛰거나 미리 알아맞히지 않아요.
  • 오른쪽을 먼저 계산하고, 그 결과를 왼쪽 이름에 저장해요. x = 3 + 4는 "3+4를 계산해서 7을 x라는 이름표 상자에 넣어라"예요. 수학의 "같다"가 아니에요.
  • print가 찍은 것만 화면에 나와요. 시험의 "실행 결과는?"은 print가 찍는 글자를 순서대로 맞히는 문제예요.
이 장을 쓰는 법 — 점점 풀이를 지워 가요

각 단계는 세 칸이에요. ① 풀이 예시는 표가 다 채워져 있으니 눈으로 따라가세요. ② 빈칸 풀이는 표의 몇 칸이 ?로 가려져 있어요. 직접 계산해 본 뒤 눌러서 확인하세요. ③ 혼자 풀기는 표 없이 종이에 직접 표를 그려 풀고 답을 열어 보세요.

왜 이렇게 하냐면, 처음부터 혼자 풀면 막막하고 풀이만 읽으면 눈에만 익고 손에는 안 남기 때문이에요. 완성된 풀이를 보고, 빈칸을 채우고, 마지막에 혼자 하는 순서가 처음 배우는 사람에게 가장 잘 남아요.

변수(variable)는 값을 담는 상자에 이름표를 붙인 거예요. a = 5는 "a 상자에 5를 넣어라"예요. 상자에는 한 번에 값 하나만 들어가서, 새 값을 넣으면 예전 값은 사라져요.

f"..."는 따옴표 안의 {이름} 자리에 그 변수의 값을 끼워 넣어 주는 문자열이에요. 읽을 때는 중괄호 안을 값으로 바꾸기만 하면 돼요.

① 풀이 예시 — 같이 따라가요

a = 5 b = a + 2 a = 10 print(a, b) print(b * 2) print(f"b는 {b}")

변수마다 열을 하나씩 만들고, 줄이 실행될 때마다 바뀐 값을 적어요. 이게 메모장 표예요.

시험엔 이렇게 써요 — 이렇게 고르세요

변수마다 열을 하나 만들고, 줄을 실행할 때마다 그 줄에서 바뀐 칸만 고쳐 적어요. 선택지를 먼저 보지 말고 표를 끝까지 채운 다음에 맞는 것을 고르세요. 답은 "print가 찍은 것"뿐이에요.

잠깐 확인 — a = 1 다음 줄에 a = a + 1이 있으면 a는 얼마인가요?

2예요. 오른쪽을 먼저 계산해(1+1=2) 그 값을 다시 a 상자에 넣어요. 예전 값 1은 사라져요.

2단계. 리스트 번호와 슬라이싱 — 번호는 0부터, 끝 칸은 빠져요

리스트(list)는 값을 한 줄로 늘어놓은 상자예요. [10, 20, 30]처럼 대괄호 안에 쉼표로 적어요. 각 칸의 번호(인덱스)는 0부터 시작해요. 자의 첫 눈금이 1cm가 아니라 0이듯, 번호는 "앞에서 몇 칸을 건너뛰었나"예요.

  • s[0]은 첫 칸, s[1]은 둘째 칸이에요. 뒤에서는 s[-1]이 마지막 칸, s[-2]가 뒤에서 둘째 칸이에요.
  • 슬라이싱 s[시작:끝]은 시작 번호부터 끝 번호 바로 앞까지 잘라요. 끝 번호 칸은 빠져요. 칸 사이의 경계선에 번호가 붙어 있고 두 경계선 사이를 자른다고 생각하면 쉬워요.
  • 시작을 비우면 맨 앞부터(s[:2]), 끝을 비우면 맨 뒤까지(s[3:])예요.

시험엔 이렇게 써요 — 이렇게 고르세요

리스트가 나오면 먼저 종이에 번호표(0, 1, 2, ...)를 그려 값 아래에 붙이세요. 그다음 [시작:끝]은 "끝 번호 칸은 빼고" 읽어요. 선택지에 끝 칸이 들어간 값이 있으면 함정이에요.

잠깐 확인 — 칸이 5개인 리스트 s에서 s[1:3]에 3번 칸 값이 들어가나요?

안 들어가요. 끝 번호 3은 "3번 칸 바로 앞까지"라는 뜻이라 1번과 2번 칸 값만 나와요.

3단계. for 반복 — 바퀴 표를 그려요

for는 같은 일을 여러 번 시키는 문장이에요. 시료 3개를 하나씩 같은 방법으로 처리하는 실험과 같아요. 들여쓰기(앞쪽 공백)로 한 줄 안쪽으로 들어간 줄들이 한 바퀴마다 반복되고, 들여쓰기가 끝난 줄은 반복이 다 끝난 뒤 한 번만 실행돼요.

  • for i in range(3)은 i가 0, 1, 2로 바뀌며 세 바퀴를 돌아요. range(n)은 0부터 n-1까지예요(슬라이싱처럼 끝 숫자는 빠져요). range(1, 4)는 1, 2, 3이에요.
  • for n in [2, 4, 6]은 리스트의 값을 앞에서부터 하나씩 n에 넣으며 세 바퀴 돌아요.
  • 리스트.append(값)은 리스트 맨 끝에 값을 덧붙여요.

따라가는 법은 바퀴마다 한 행을 적는 거예요. 왜냐하면 반복문의 결과는 "몇 바퀴째에 변수가 어떻게 바뀌나"로만 정해지기 때문이에요.

total = 0 for i in range(3): total = total + i print(i, total) print("끝", total)

시험엔 이렇게 써요 — 이렇게 고르세요

for가 나오면 먼저 "몇 바퀴, 각 바퀴에서 변수 값은?"을 적어요. 그다음 들여쓴 줄을 바퀴마다 한 번씩 실행해 바퀴 표를 채워요. print의 들여쓰기 위치를 꼭 확인하세요.

잠깐 확인 — range(5)가 만드는 숫자는 무엇인가요?

0, 1, 2, 3, 4예요. 모두 5개이고 끝 숫자 5는 들어가지 않아요.

4단계. 함수 호출 — 넣으면 돌려주는 작은 기계

함수(function)는 이름을 붙여 둔 작은 기계예요. def 이름(재료):로 기계를 만들어 두기만 하고, 이름(값)처럼 부를 때 비로소 안쪽 줄이 실행돼요. 믹서기를 사 놓기만 하면 아무것도 갈리지 않는 것과 같아요.

  • 호출하면 값이 괄호 안 이름표(매개변수)에 순서대로 들어가요. area(3, 4)면 w=3, h=4예요.
  • return 값을 만나면 그 값이 호출한 자리로 돌아가 호출 부분을 대신해요. 그래서 a = area(3, 4)는 a = 12와 같아져요.
  • y=1처럼 = 이 붙은 이름은 기본값이에요. 호출할 때 값을 주지 않으면 이 값이 쓰여요.

시험엔 이렇게 써요 — 이렇게 고르세요

호출이 나오면 "누가 어떤 이름표에 들어가나"를 w, h 같은 열로 적고, 안쪽을 계산해 return 값을 호출 자리에 갈아 끼우세요. print는 화면에 찍기, return은 값을 돌려주기라서 둘은 다른 일이에요.

잠깐 확인 — def만 쓰고 한 번도 부르지 않으면 함수 안쪽 줄이 실행되나요?

안 돼요. def는 만들어 두기만 해요. 이름(값)으로 호출해야 실행돼요.

5단계. 텐서 shape 읽기 — 숫자 하나는 줄이고, 범위는 남겨요

텐서(Tensor)는 숫자를 격자 모양으로 담은 상자예요. shape는 방향마다 칸이 몇 개인지를 적은 거예요. (2, 3)은 2줄 × 3칸이고, 시료 트레이가 2줄에 3칸씩 있는 모양이에요. shape의 숫자를 모두 곱하면 숫자 전체 개수예요(2×3=6).

  • torch.arange(6)은 0, 1, 2, 3, 4, 5를 만들어요(range처럼 끝 숫자는 빠져요).
  • .reshape(2, 3)은 같은 숫자들을 새 모양으로 다시 채워요. 곱이 같아야 해요. 숫자 하나 자리에 -1을 쓰면 "나머지는 알아서 계산해"라는 뜻이에요.
  • 텐서 번호도 0부터예요. x[:, 1]은 "모든 줄(:)에서 1번 칸"이에요.
외우기 팁 — 가장 중요한 규칙

번호를 숫자 하나로 뽑으면(x[:, 1]) 그 방향 칸이 사라져요. 번호를 범위로 뽑으면(x[:, 1:2]) 그 방향 칸이 1개짜리로 남아요. 이 한 쌍이 시험 1번이에요.

① 풀이 예시 — 같이 따라가요

잠깐 확인 — 12개짜리를 reshape(5, -1)로 바꿀 수 있나요?

6단계. nn.Linear(in, out) — 출력 shape와 파라미터 수

nn.Linear(3, 2)는 "입력 숫자 3개를 받아 출력 숫자 2개를 내놓는 계산기 한 층"이에요. 재료 3가지를 넣으면 점수 2개가 나오는 계산기를 떠올리면 돼요. 괄호 안 순서는 (입력 개수 in, 출력 개수 out)이에요.

  • 입력 shape는 (샘플 수, in)이어야 하고 출력 shape는 (샘플 수, out)이에요. 샘플 수 칸은 그대로 두고 마지막 칸만 in에서 out으로 바뀐다고 읽으세요.
  • 이 층이 학습으로 고치는 값(파라미터)은 두 가지예요. weight의 shape는 (out, in)이고 bias의 shape는 (out,)예요.
  • 파라미터 개수는 in × out + out이에요. weight 칸 수 in×out에 bias 칸 수 out을 더한 거예요.

sum(p.numel() for p in fc.parameters())는 길어 보이지만 "이 층의 모든 파라미터 숫자 개수의 합"이라고만 읽으세요. 문법을 풀어 쓸 필요는 없어요.

① 풀이 예시 — 같이 따라가요

import torch from torch import nn fc = nn.Linear(3, 2) x = torch.ones(4, 3) y = fc(x) print(tuple(y.shape)) print(tuple(fc.weight.shape), tuple(fc.bias.shape)) print(sum(p.numel() for p in fc.parameters()))

시험엔 이렇게 써요 — 이렇게 고르세요

Linear(in, out)이 보이면 세 가지만 하세요. ① 입력의 마지막 칸이 in인지 확인. ② 출력은 마지막 칸만 out으로. ③ 파라미터 개수는 in×out+out. 층이 여러 개면 앞 층의 out이 다음 층의 in과 같아야 이어져요.

(7, 2)예요. 샘플 수 7은 그대로이고 마지막 칸 4가 out인 2로 바뀌어요.

7단계. DataLoader — 배치 개수와 마지막 배치

Dataset은 (입력, 정답) 쌍을 번호로 꺼낼 수 있게 묶어 둔 명부이고, DataLoader는 그 명부에서 batch_size개씩 묶어 순서대로 내주는 트레이예요. 시료 7개를 3개씩 트레이에 담으면 3개, 3개, 1개가 되는 것과 같아요.

  • len(ds)는 샘플 총 개수예요. len(loader)는 배치(트레이) 개수예요.
  • 배치 개수는 샘플 수 ÷ batch_size를 올림한 값이고, 마지막 배치는 남은 개수만 담겨요(7 ÷ 3이면 3개, 3개, 1개).
  • drop_last=True이면 모자란 마지막 배치를 버려요. 그래서 배치 개수는 내림한 값이 돼요.
  • shuffle=False면 번호 순서대로 담겨요. shuffle=True면 어떤 번호가 들어갈지는 매번 달라지지만 개수는 그대로예요.
  • for 반복이 끝난 뒤에도 bx, by는 마지막 배치 값으로 남아 있어요. 시험 샘플 4번이 바로 이걸 물어봐요.

① 풀이 예시 — 같이 따라가요

import torch from torch.utils.data import TensorDataset, DataLoader x = torch.arange(7) y = x * 10 ds = TensorDataset(x, y) loader = DataLoader(ds, batch_size=3, shuffle=False) print(len(ds), len(loader)) for bx, by in loader: print(bx.tolist()) print(bx.tolist())

x는 0부터 6까지 7개, y는 그 10배예요. batch_size가 3이라서 번호를 3개씩 끊어요.

8단계. 학습 5줄 — zero_grad, forward, loss, backward, step

딥러닝 학습은 매 바퀴 같은 5줄을 반복해요. 순서와 역할을 외우면 대부분의 문제가 풀려요.

순서코드하는 일 (한 줄)
1optimizer.zero_grad()지난 바퀴에 쌓인 기울기(grad)를 지워요
2prediction = model(x)예측값을 계산해요 (forward)
3loss = criterion(prediction, y)예측과 정답의 차이를 숫자 하나(loss)로 만들어요
4loss.backward()기울기를 계산해 .grad에 저장만 해요. 파라미터 값은 안 바뀌어요
5optimizer.step()저장된 기울기로 파라미터 값을 실제로 고쳐요
외우기 팁

"비우고 → 예측하고 → 재고 → 기울기 구하고 → 한 걸음". 값이 바뀌는 건 마지막 step 한 줄뿐이에요. 기울기는 w - lr × grad로 w를 고치는 재료일 뿐이에요.

아래 예시는 모델 없이 값 하나(w)만 키워서 5줄이 실제로 숫자를 어떻게 바꾸는지 눈으로 보는 거예요. loss는 (w - 5)²이라서 w가 5에 가까울수록 작아요. 이때 기울기는 2 × (w - 5)이고, 계산은 컴퓨터가 해 주니 표에서는 값만 받아 적으세요. 학습률 lr은 한 걸음 크기예요.

① 풀이 예시 — 같이 따라가요

import torch w = torch.tensor(1.0, requires_grad=True) optimizer = torch.optim.SGD([w], lr=0.25) for step in range(3): optimizer.zero_grad() loss = (w - 5) ** 2 loss.backward() optimizer.step() print(step, w.grad.item(), w.item())

③ 혼자 풀기 — 첫 예시와 똑같은데 optimizer.zero_grad() 줄이 빠졌어요. 기울기를 지우지 않으면 새 기울기가 이전 값에 더해져서 쌓여요. 두 줄을 적어 보세요.

w = torch.tensor(1.0, requires_grad=True) optimizer = torch.optim.SGD([w], lr=0.25) for step in range(2): loss = (w - 5) ** 2 loss.backward() optimizer.step() print(w.grad.item(), w.item())
답 보기
-8.0 3.0 -12.0 6.0

0바퀴는 처음이라 grad가 -8.0이고 w = 1 - 0.25×(-8) = 3.0이에요. 1바퀴에서 새 기울기는 2×(3-5) = -4인데, 지우지 않아서 이전 -8에 더해져 grad가 -12.0이 돼요. 그래서 w = 3 - 0.25×(-12) = 6.0이 되어 5를 지나쳐 버려요. zero_grad가 필요한 이유가 이거예요.

시험엔 이렇게 써요 — 이렇게 고르세요

학습 5줄 문제는 이렇게 답하세요. loss.backward()는 기울기를 계산해 저장만 하고 파라미터 값은 바꾸지 않는다. optimizer.step()은 저장된 기울기로 옵티마이저에 전달된 파라미터를 갱신한다. optimizer.zero_grad()는 쌓인 기울기를 지우는 것이지 파라미터 값을 0으로 만드는 게 아니다. 샘플 5번의 정답이 이 문장이에요.

잠깐 확인 — loss.backward()를 부르면 w의 값이 바뀌나요?

안 바뀌어요. backward는 기울기를 계산해 w.grad에 저장만 해요. 값을 바꾸는 건 optimizer.step()이에요.
