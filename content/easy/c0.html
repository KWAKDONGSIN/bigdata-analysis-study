왕초보 코드 읽기 — 코드는 "순서대로 하는 일 목록"이에요

이 시험은 코드를 직접 짜지 않아요. 주어진 코드를 읽고 결과를 고르는 객관식이에요. 그래서 파이썬을 전혀 몰라도 "한 줄씩 손으로 따라가는 법"만 익히면 돼요. 이 장은 시험 코드에 나오는 문법만 골라서 가장 쉬운 말로 설명해요.

비유 — 실험 프로토콜

식품공학 실험 노트를 떠올려 보세요. "시료 10g 칭량 → 물 50mL 첨가 → 5분 교반 → 결과 기록"처럼 위에서 아래로 한 단계씩 해요. 코드도 똑같아요. 컴퓨터는 위에서 아래로 한 줄씩, 적힌 순서대로만 일해요.

0-1. 코드 읽기의 기본 — 위에서 아래로, 화면에 나온 것만 결과

코드(code)는 컴퓨터에게 시키는 일 목록이에요. 이 목록을 컴퓨터가 차례로 해 보는 것을 실행한다고 해요. 실행했을 때 화면에 찍히는 글자가 출력(결과)이에요.

화면에 글자를 찍으라는 명령이 print(...)예요. 시험의 "실행 결과는?" 문제는 결국 print가 찍는 글자를 순서대로 맞히는 일이에요.

print("안녕") print(3 + 4) # 이 줄은 '주석'이에요. 사람이 읽으라고 적은 메모라서 컴퓨터는 무시해요. print("끝")
안녕 7 끝
코드 줄무슨 뜻
print("안녕")따옴표 안의 글자를 그대로 화면에 찍어요
print(3 + 4)괄호 안을 먼저 계산(3+4=7)하고 그 결과를 찍어요
# ...#으로 시작하면 주석이에요. 실행되지 않아요

코드가 틀리면 컴퓨터가 에러(Error)라는 빨간 글씨를 띄우고 멈춰요. 시험 선택지에 "에러가 발생한다"가 있으면 "이 줄에서 규칙이 어긋났나?"를 확인하면 돼요. 이 장 곳곳에 자주 나오는 에러를 함께 적어 두었어요.

시험엔 이렇게 써요 — 이렇게 고르세요

① 맨 위 줄부터 한 줄씩 내려가요. ② print를 만날 때마다 결과를 한 줄씩 적어요. ③ print가 없는 줄은 값만 바꿀 뿐 화면에는 아무것도 안 나와요. 그래서 결과 줄 수는 "실제로 실행된 print 횟수"와 같아요.

잠깐 확인 — 코드에 print가 3번 있고 각각 한 번씩 실행되면 결과는 몇 줄인가요?

3줄이에요. print 한 번이 한 줄을 찍어요(반복문 안에 있으면 반복 횟수만큼 찍혀요).

0-2. 변수 — 이름표가 붙은 상자 ★★

변수(variable)는 값을 담아 두는 상자에 이름표를 붙인 거예요. x = 5는 "x라는 이름표 상자에 5를 넣어라"예요.

한 줄 정의

=는 "같다"가 아니라 "오른쪽 값을 왼쪽 상자에 넣어라"예요. 오른쪽을 먼저 계산하고, 그 결과를 왼쪽 이름표 상자에 넣어요.

비유

시약병에 라벨을 붙이는 것과 같아요. 라벨(x)이 붙은 병에 새 시약을 부으면 원래 들어 있던 시약은 없어져요. 변수에 새 값을 넣으면 이전 값은 사라져요.

x = 5 y = x + 2 x = 10 print(x, y) n = 5 n = n + 1 print(n) n += 2 print(n)
10 7 6 8
코드 줄실행 후 상자 상태
x = 5x는 5
y = x + 2x(5)+2 = 7이 y에 들어가요. x는 5, y는 7
x = 10x가 10으로 바뀌어요. y는 그대로 7이에요 (한 번 계산해서 넣은 값이라 따라 바뀌지 않아요)
print(x, y)쉼표로 이어 쓰면 한 줄에 칸을 띄워 찍어요 → 10 7
n = n + 1"지금 n에 1을 더해서 다시 n에 넣어라". 5 → 6
n += 2n = n + 2를 줄여 쓴 거예요. 6 → 8

왜 y가 안 바뀌나요? y에는 "그 순간 계산한 결과 숫자 7"이 들어갔을 뿐, "x+2라는 식"이 들어간 게 아니기 때문이에요. 시험에서 가장 흔한 함정이에요.

시험엔 이렇게 써요 — 이렇게 고르세요

변수가 둘 이상이면 시험지 여백에 변수표(x=?, y=?)를 만들어요. 한 줄 실행할 때마다 표의 값만 고쳐 쓰면 실수가 거의 없어요. +=는 "지금 값에 더해서 다시 넣기"예요.

잠깐 확인 — a = 3, b = a * 2, a = 100 을 차례로 실행하면 b는 얼마인가요?

6이에요. b는 a가 3일 때 계산한 6을 받았고, 나중에 a가 100이 되어도 따라 바뀌지 않아요.

0-3. 숫자, 글자(문자열), 계산, 참과 거짓

코드에 나오는 값은 크게 세 종류예요. 숫자, 글자, 참/거짓이에요.

종류모양 예시설명
정수7, -3소수점이 없는 숫자
실수3.5, 1.0소수점이 있는 숫자. 1.0처럼 .0이 붙으면 실수예요
문자열"Bori"따옴표로 감싼 글자. 따옴표가 없으면 변수 이름이에요
참/거짓True, False맞다/아니다. 첫 글자가 대문자예요

계산 기호는 아래와 같아요.

기호예결과와 설명

글자와 글자도 +로 이어 붙일 수 있고, len(...)은 길이를 세요. 글자 속에 변수 값을 끼워 넣고 싶을 때는 따옴표 앞에 f를 붙이고 { } 안에 변수를 써요. 이것을 f-string이라고 해요.

name = "Bori" print("Hi " + name) print(f"{name}가 멍멍 짖습니다.") print(len(name)) print(7 / 2, 2 ** 3) print(5 == 5, 3 >= 4) print(f"{3.14159:.2f}")
Hi Bori Bori가 멍멍 짖습니다. 4 3.5 8 True False 3.14
코드 줄무슨 뜻
"Hi " + name글자 이어 붙이기. 뒤에 공백이 있으니 "Hi Bori"
f"{name}가 멍멍 짖습니다."중괄호 자리에 name의 값(Bori)이 들어가요
len(name)글자 수 B-o-r-i = 4
f"{3.14159:.2f}":.2f는 "소수 둘째 자리까지"예요. 3.14가 찍혀요
시험엔 이렇게 써요 — 이렇게 고르세요

f-string은 "중괄호 자리를 변수 값으로 바꿔서 읽기"만 하면 끝이에요. /는 항상 소수가 나오고(7/2=3.5), ==는 같은지 묻는 기호라는 두 가지만 기억하세요.

잠깐 확인 — x = "Kim"일 때 print(f"{x}님")은 무엇을 찍나요?

Kim님이에요. 중괄호 자리에 x의 값이 들어가요.

0-4. 리스트와 인덱스, 슬라이싱 ★★★ 시험 단골

리스트(list)는 값을 대괄호 [ ]로 묶어 줄 세운 거예요. 칸마다 번호가 있고, 번호는 0부터 시작해요. 이 번호를 인덱스(index)라고 해요.

비유

자(ruler)의 눈금은 1cm가 아니라 0cm에서 시작해요. 리스트의 첫 칸도 "1번"이 아니라 "0번"이에요. 0번이 있어서 마지막 칸 번호는 "개수 − 1"이에요.

리스트 a1020304050
앞에서 센 번호01234
뒤에서 센 번호-5-4-3-2-1

뒤에서부터 세고 싶으면 마이너스 번호를 써요. -1은 맨 마지막 칸이에요.

여러 칸을 한꺼번에 꺼내는 것이 슬라이싱(slicing)이에요. 모양은 a[시작:끝]이고, 끝 번호의 칸은 포함하지 않아요. "시작 칸부터 끝 번호 바로 앞 칸까지"예요.

a = [10, 20, 30, 40, 50] print(a[0]) print(a[-1]) print(a[1:3]) print(a[:2]) print(a[2:]) print(a[::2]) print(len(a)) a.append(60) print(a)
10 50 [20, 30] [10, 20] [30, 40, 50] [10, 30, 50] 5 [10, 20, 30, 40, 50, 60]
코드 줄무슨 뜻
a[0]0번 칸 → 10
a[-1]맨 마지막 칸 → 50
a[1:3]1번 칸부터 3번 앞까지 → 1번, 2번 칸 → [20, 30]. 개수는 3−1 = 2개
a[:2]시작을 비우면 "처음부터". 0번, 1번 칸 → [10, 20]
a[2:]끝을 비우면 "끝까지". 2번 칸부터 마지막까지
a[::2]맨 끝의 숫자는 간격(보폭)이에요. 2칸씩 건너뛰며 → 10, 30, 50
len(a)칸 개수 = 5. 마지막 번호(4)보다 1 커요
a.append(60)리스트 맨 뒤에 60을 덧붙여요. 점(.) 쓰는 법은 0-8에서 설명해요

왜 끝 번호를 포함하지 않을까요? 이렇게 하면 a[0:2]와 a[2:5]를 이어 붙였을 때 빠지거나 겹치는 칸이 없어서 깔끔하기 때문이에요. 이 규칙은 다음 장 Tensor 슬라이싱에서 그대로 쓰여요.

소괄호로 묶은 튜플(tuple)도 자주 나와요. 리스트와 거의 같은데 값을 바꿀 수 없어요. 특히 원소가 하나뿐인 튜플은 쉼표를 꼭 붙여서 (3,)이라고 써요. 그냥 (3)이면 괄호 친 숫자 3일 뿐이라서 구분하려고 쉼표를 붙여요. 시험 선택지의 (3,)은 "원소가 3개인 한 줄"이라는 뜻이에요(2장).

시험엔 이렇게 써요 — 이렇게 고르세요

슬라이싱 문제는 먼저 칸마다 0, 1, 2, …번호를 써 놓고 풀어요. [시작:끝]은 "시작 칸부터 끝 칸 바로 앞까지"이고 개수는 끝 − 시작이에요. 마이너스 번호는 뒤에서부터 세요.

잠깐 확인 — b = [5, 6, 7, 8, 9]일 때 b[1:4]와 b[-2:]는?

b[1:4]는 1, 2, 3번 칸이라서 [6, 7, 8]이에요. b[-2:]는 뒤에서 두 번째부터 끝까지라서 [8, 9]예요.

0-5. 함수 — 이름 붙은 작은 기계 (def, return) ★★

함수(function)는 "재료를 넣으면 결과를 내주는 작은 기계"예요. 한 번 만들어 두면 이름만 불러서 계속 쓸 수 있어요. 함수를 만드는 명령이 def이고, 결과를 내보내는 명령이 return이에요.

비유

착즙기를 떠올려 보세요. 과일(입력)을 넣으면 주스(출력)가 나와요. def는 착즙기를 설계해 두는 일이고, add(3, 4)처럼 이름을 부르는 것이 착즙기를 실제로 돌리는 일이에요. 설계만 해 두고 안 돌리면 주스는 안 나와요.

def add(p, q): return p + q r = add(3, 4) print(r) def twice(x): print(x * 2) r = twice(3) print(r) def greet(name, times=1): return (name + " ") * times print(greet("A")) print(greet("A", 2))
7 6 None A A A
코드 줄무슨 뜻
def add(p, q):"add라는 기계를 만든다. 재료 두 개(p, q)를 받는다". 끝의 콜론(:)과 아래 줄의 들여쓰기가 규칙이에요
return p + q들여쓴 줄은 함수 안쪽이에요. p+q를 계산해서 "돌려주고" 함수를 끝내요
r = add(3, 4)add를 실행해요(p=3, q=4). 돌려받은 7이 r에 들어가요
print(r)7을 찍어요
r = twice(3)twice 안에서 print(6)이 실행돼 6이 화면에 찍혀요. 그런데 twice에는 return이 없어서 r에는 None(아무것도 없음)이 들어가요
print(r)None을 찍어요
times=1기본값이에요. 값을 안 넘기면 1을 쓰고, 넘기면 넘긴 값을 써요. greet("A")는 "A"를 한 번, greet("A", 2)는 두 번 이어서 "AA"가 돼요

print와 return은 달라요. print는 화면에 글자를 보여 줄 뿐이고, return은 값을 함수 밖으로 돌려줘요. 돌려받은 값을 변수에 넣어 다음 계산에 쓸 수 있는 건 return이에요.

시험엔 이렇게 써요 — 이렇게 고르세요

① def 블록은 정의만으로는 아무 일도 안 해요. 이름을 불러(호출) 줄 때 비로소 실행돼요. ② 호출하면 인자를 순서대로 재료 칸에 넣고 들여쓴 줄을 위에서 아래로 실행해요. ③ return을 만나면 값을 들고 바로 빠져나와요.

잠깐 확인 — def f(x): 안에 return이 없고 print(x)만 있습니다. y = f(5)를 하면 y에는 무엇이 들어 있나요?

None이에요. 5는 화면에 찍히지만 돌려준 값이 없기 때문이에요.

0-6. 반복 — for와 range, 그리고 들여쓰기 ★★

for는 같은 일을 여러 번 되풀이하는 명령이에요. range(4)는 "0, 1, 2, 3"을 차례로 내주는 도구예요. 0부터 시작하고 끝 숫자(4)는 포함하지 않아요. 슬라이싱과 같은 규칙이에요.

total = 0 for i in range(4): total = total + i print(i, total) print(list(range(0, 10, 4)))
0 0 1 1 2 3 3 6 [0, 4, 8]
바퀴itotal 계산찍히는 결과
100 + 0 = 00 0
210 + 1 = 11 1
321 + 2 = 32 3
433 + 3 = 63 6

range(0, 10, 4)처럼 숫자 세 개를 쓰면 range(시작, 끝, 간격)이에요. 0에서 시작해 4씩 더하다가 10 이상이 되면 멈춰서 0, 4, 8이 나와요. 데이터 10개를 4개씩 묶어 꺼낼 때 이 모양을 쓰고, 그래서 묶음이 3개(4개, 4개, 2개)가 돼요.

반복할 범위는 들여쓰기로 정해요. 들여쓴 줄만 매 바퀴 반복되고, 들여쓰지 않은 줄은 반복이 다 끝난 뒤 한 번만 실행돼요.

total = 0 for i in range(3): total = total + i print("안", total) print("밖", total)
안 0 안 1 안 3 밖 3

리스트의 값을 하나씩 꺼내 쓰는 것도 같은 for예요. 값이 짝으로 묶여 있으면 for p, q in pairs:처럼 변수 두 개로 한꺼번에 받을 수 있어요. 나중에 나올 for batch_x, batch_y in loader:도 "꺼낸 묶음이 (입력, 정답) 짝이라서 둘로 나눠 받는다"는 같은 모양이에요.

pairs = [(1, 10), (2, 20)] for p, q in pairs: print(p, q) a1, b1 = 3, 4 print(a1, b1)
1 10 2 20 3 4
외우기 팁

range(n)은 0부터 n−1까지, 총 n번. "끝 숫자는 빠진다"만 기억하세요. 그리고 들여쓴 줄 = 반복 안이에요.

시험엔 이렇게 써요 — 이렇게 고르세요

for 문제는 위 표처럼 바퀴마다 한 줄씩 표를 그려요. 바퀴 수는 range의 개수예요. print가 들여쓴 줄 안에 있으면 바퀴 수만큼, 바깥에 있으면 한 번만 찍혀요.

잠깐 확인 — range(2, 8, 3)이 내주는 숫자는?

2, 5예요. 2에서 시작해 3씩 더하면 2, 5, 8인데 8은 끝 숫자(8)와 같아서 포함되지 않아요.

0-7. 조건 — if, elif, else와 한 줄 조건식

if는 "조건이 맞을 때만 실행해라"예요. 조건이 틀리면 elif(그게 아니고 이것이 맞으면), 모두 틀리면 else(나머지 전부) 줄이 실행돼요. 위에서부터 보다가 처음으로 맞는 하나만 실행하고 나머지는 건너뛰어요.

score = 85 if score >= 90: print("A") elif score >= 80: print("B") else: print("C")
B
코드 줄무슨 뜻
if score >= 90:85 >= 90은 False라서 아래 줄을 건너뛰어요
elif score >= 80:85 >= 80은 True라서 print("B") 실행. 그리고 if 묶음 전체가 끝나요
else:앞이 다 틀렸을 때만. 이번엔 실행 안 돼요

조건이 맞는지에 따라 값을 고르는 한 줄짜리 모양도 자주 나와요. 값1 if 조건 else 값2 형태이고 "조건이 맞으면 값1, 아니면 값2"예요. GPU 장에서 보는 'cuda' if torch.cuda.is_available() else 'cpu'가 바로 이 모양이에요.

cuda_ok = False device = 'cuda' if cuda_ok else 'cpu' print(device) print(max(0, 5 - 20), min(3, 9))
cpu 0 3

max(a, b)는 큰 쪽, min(a, b)는 작은 쪽을 돌려줘요. max(0, 5 - 20)은 5−20 = −15와 0 중 큰 쪽이라서 0이에요. "음수가 되면 0으로 막아 둔다"는 뜻으로 클래스 예제(자동차 속도)에 나와요.

시험엔 이렇게 써요 — 이렇게 고르세요

if-elif-else는 위에서부터 조건을 하나씩 확인하고 처음 True인 줄 하나만 실행해요. A if 조건 else B는 먼저 조건이 True인지 False인지 정한 뒤 A 또는 B를 골라요.

잠깐 확인 — x = 3일 때 'big' if x >= 5 else 'small'의 값은?

'small'이에요. 3 >= 5는 False라서 else 쪽 값을 골라요.

0-8. import와 점(.) 표기 — 도구 상자에서 도구 꺼내기 ★★

파이썬에는 남들이 만들어 둔 도구 상자(라이브러리, 또는 모듈)가 많아요. 쓰려면 먼저 import로 상자를 가져와요. 딥러닝 도구 상자의 이름이 torch(파이토치)예요.

상자 안의 도구를 꺼낼 때는 점(.)을 써요. 점은 "~ 안의"라고 읽으면 돼요. torch.arange는 "torch 안의 arange"예요.

코드읽는 법
import torchtorch 상자를 가져와요. 이제 torch.도구이름으로 써요
import numpy as npnumpy 상자를 가져오되 "np"라는 짧은 별명으로 불러요
import torch.nn as nntorch 안의 nn 칸을 "nn"이라는 별명으로 가져와요
from torch import nn위와 같은 효과예요. torch에서 nn만 꺼내 와요
from torch.utils.data import TensorDataset, DataLoadertorch.utils.data 칸에서 두 가지(TensorDataset, DataLoader)를 꺼내 와요

점은 두 가지 뜻으로 쓰여요. 괄호가 있느냐 없느냐가 차이예요.

모양뜻예
대상.이름 (괄호 없음)대상이 가진 정보(속성)를 읽어요x.shape, x.dtype, self.name
대상.이름(...) (괄호 있음)대상에게 동작을 시켜요(메서드 호출)x.reshape(3, 4), a.append(60)

괄호 종류도 헷갈리기 쉬워요. ( )는 함수 호출이나 계산 묶음, [ ]는 리스트와 번호 매기기(인덱스), { }는 f-string에서 값이 들어갈 자리(그리고 딕셔너리)를 뜻해요. {"loss": 0.5}처럼 이름표와 값 쌍을 묶은 것을 딕셔너리라고 하고, d["loss"]로 꺼내요.

시험엔 이렇게 써요 — 이렇게 고르세요

import 줄은 "도구를 가져오는 준비 단계"라서 결과에는 영향이 없어요. 그 아래에서 torch.이나 nn.으로 시작하는 줄이 진짜 일을 해요. 점 뒤에 괄호가 있으면 동작, 없으면 정보 읽기라고 구분하세요.

잠깐 확인 — x.shape와 x.sum() 중 괄호가 필요한 것은?

x.sum()이에요. shape는 x가 가진 정보를 읽을 뿐이라 괄호가 없고, sum은 합을 구하라는 동작이라 괄호가 있어요.

0-10. 시험 코드 손으로 따라가기 — 5단계 요령 ★★★

0-1부터 0-9까지 배운 것을 모아서, 어떤 코드든 이 순서로 따라가면 돼요.

  • 1단계 — 실제로 실행되는 줄부터 찾아요. import, def, class로 시작하는 덩어리는 "정의"일 뿐이에요. 아래에서 호출될 때 비로소 실행돼요.
  • 2단계 — 변수표를 만들어요. 시험지 여백에 변수 이름을 적고 값을 채워요.
  • 3단계 — 한 줄 실행할 때마다 표를 고쳐요. =는 오른쪽 계산 후 왼쪽에 넣기이고, 함수 호출을 만나면 그 함수 안으로 들어갔다 와요.
  • 4단계 — print를 만나면 결과 칸에 한 줄 적어요. 반복문 안이면 바퀴마다 적어요.
  • 5단계 — 내 결과와 선택지를 비교해요. 한눈에 틀린 선택지(칸 수, 개수, 첫 줄)부터 지우면 시간이 줄어요.

직접 해 볼까요? 아래 코드를 위 5단계로 따라가 보세요.

def double(n): return n * 2 nums = [1, 2, 3, 4] out = [] for v in nums: if v >= 3: out.append(double(v)) print(out) print(len(out), out[0], out[-1])
바퀴vv >= 3 ?out의 상태

마지막 줄은 len(out) = 2, out[0] = 6(첫 칸), out[-1] = 8(마지막 칸)이에요. 함수 double은 정의만 되어 있다가 for 안에서 호출될 때 실행돼요.

시험엔 이렇게 써요 — 이렇게 고르세요

코드를 보자마자 답을 추측하지 말고 변수표 + 바퀴표로 따라간 뒤 선택지와 비교하세요. 처음엔 느려 보여도 가장 정확해요. 교수님은 객관식 20문제 안팎, 60~70분 정도로 생각 중이라고 했어요(아직 확정은 아니에요). 문제당 3분 정도는 쓸 수 있어요.

잠깐 확인 — 위 코드에서 조건을 v >= 2로 바꾸면 print(out)은?

[4, 6, 8]이에요. v가 2, 3, 4일 때 각각 두 배를 덧붙여요.

이 장 3줄 요약
  • 코드는 위에서 아래로 한 줄씩 실행되고, =는 "오른쪽 계산 결과를 왼쪽 이름표 상자에 넣기"이며, 결과는 print가 찍은 글자만 세요.
  • 리스트 번호는 0부터이고 a[시작:끝]은 끝 칸을 빼요. range(n)도 0부터 n−1까지예요. 들여쓴 줄만 반복(또는 함수 안쪽)이에요.
  • def는 정의일 뿐 호출해야 실행되고, return은 값을 돌려주며 print는 화면에만 찍어요. 점(.)은 "~ 안의"이고 괄호가 있으면 동작이에요.
