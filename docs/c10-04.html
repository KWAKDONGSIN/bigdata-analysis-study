4단계. 함수 호출 — 넣으면 돌려주는 작은 기계

함수(function)는 이름을 붙여 둔 작은 기계예요. def 이름(재료):로 기계를 만들어 두기만 하고, 이름(값)처럼 부를 때 비로소 안쪽 줄이 실행돼요. 믹서기를 사 놓기만 하면 아무것도 갈리지 않는 것과 같아요.

  • 호출하면 값이 괄호 안 이름표(매개변수)에 순서대로 들어가요. area(3, 4)면 w=3, h=4예요.
  • return 값을 만나면 그 값이 호출한 자리로 돌아가 호출 부분을 대신해요. 그래서 a = area(3, 4)는 a = 12와 같아져요.
  • y=1처럼 = 이 붙은 이름은 기본값이에요. 호출할 때 값을 주지 않으면 이 값이 쓰여요.

① 풀이 예시 — 같이 따라가요

def area(w, h): return w * h a = area(3, 4) b = area(a, 2) print(a, b)
실행하는 일w, h돌려준 값ab
1~2줄def → 기계를 만들어 두기만 해요 (아직 실행 안 함)----
4줄area(3, 4) 호출 → w=3, h=4, 3×43, 41212-
5줄area(a, 2) 호출 → a는 지금 12라서 w=12, h=2, 12×212, 2241224
6줄print(a, b)--1224
12 24

화면에는 마지막 print의 12 24 한 줄만 나와요. 함수 안의 계산은 return으로 값을 돌려줄 뿐 화면에 찍지 않기 때문이에요.

③ 혼자 풀기 — 화면에 나오는 두 줄을 적어 보세요. show 함수에 return이 있는지부터 보세요.

def show(n): print(n * 2) r = show(4) print(r)
답 보기
8 None

show(4)를 부르면 안쪽 print가 4×2=8을 화면에 찍어요(첫 줄). 그런데 show에는 return이 없어서 돌려주는 값이 없고, 이때 파이썬은 None(아무것도 없음)을 돌려줘요. 그래서 r은 None이고 두 번째 print가 None을 찍어요.

시험엔 이렇게 써요 — 이렇게 고르세요

호출이 나오면 "누가 어떤 이름표에 들어가나"를 w, h 같은 열로 적고, 안쪽을 계산해 return 값을 호출 자리에 갈아 끼우세요. print는 화면에 찍기, return은 값을 돌려주기라서 둘은 다른 일이에요.

잠깐 확인 — def만 쓰고 한 번도 부르지 않으면 함수 안쪽 줄이 실행되나요?

안 돼요. def는 만들어 두기만 해요. 이름(값)으로 호출해야 실행돼요.
