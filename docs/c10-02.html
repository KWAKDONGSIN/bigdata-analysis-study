2단계. 리스트 번호와 슬라이싱 — 번호는 0부터, 끝 칸은 빠져요

리스트(list)는 값을 한 줄로 늘어놓은 상자예요. [10, 20, 30]처럼 대괄호 안에 쉼표로 적어요. 각 칸의 번호(인덱스)는 0부터 시작해요. 자의 첫 눈금이 1cm가 아니라 0이듯, 번호는 "앞에서 몇 칸을 건너뛰었나"예요.

  • s[0]은 첫 칸, s[1]은 둘째 칸이에요. 뒤에서는 s[-1]이 마지막 칸, s[-2]가 뒤에서 둘째 칸이에요.
  • 슬라이싱 s[시작:끝]은 시작 번호부터 끝 번호 바로 앞까지 잘라요. 끝 번호 칸은 빠져요. 칸 사이의 경계선에 번호가 붙어 있고 두 경계선 사이를 자른다고 생각하면 쉬워요.
  • 시작을 비우면 맨 앞부터(s[:2]), 끝을 비우면 맨 뒤까지(s[3:])예요.

① 풀이 예시 — 같이 따라가요

s = [10, 20, 30, 40, 50] print(s[0]) print(s[-1]) print(s[1:3]) print(s[:2]) print(len(s))
앞에서 번호01234
값1020304050
뒤에서 번호-5-4-3-2-1
코드따라가기화면에 나온 것
print(s[0])앞 번호 0 → 1010
print(s[-1])뒤 번호 -1 → 맨 마지막 5050
print(s[1:3])번호 1, 2번 칸 (3번은 빠짐) → 20, 30[20, 30]
print(s[:2])처음부터 번호 0, 1번 칸 → 10, 20[10, 20]
print(len(s))len은 칸 수 → 5칸5
10 50 [20, 30] [10, 20] 5

슬라이싱 결과는 값 하나가 아니라 리스트라서 대괄호가 붙어서 나와요. s[1]은 20(값 하나), s[1:2]는 [20](리스트)예요. 이 차이는 5단계의 텐서에서 그대로 다시 나와요.

③ 혼자 풀기 — 종이에 번호표(앞 번호와 값)를 먼저 그리고 풀어 보세요.

t = [3, 1, 4, 1, 5, 9] print(t[1:4]) print(t[-3:]) print(t[2] + t[-1])
답 보기
[1, 4, 1] [1, 5, 9] 13

t의 번호표는 0→3, 1→1, 2→4, 3→1, 4→5, 5→9예요. t[1:4]는 1, 2, 3번 칸이라 1, 4, 1이에요. t[-3:]은 뒤에서 셋째 칸부터 끝까지라 1, 5, 9예요. 마지막은 t[2]=4와 t[-1]=9를 더한 13이고, 이건 리스트가 아니라 숫자 하나예요.

시험엔 이렇게 써요 — 이렇게 고르세요

리스트가 나오면 먼저 종이에 번호표(0, 1, 2, ...)를 그려 값 아래에 붙이세요. 그다음 [시작:끝]은 "끝 번호 칸은 빼고" 읽어요. 선택지에 끝 칸이 들어간 값이 있으면 함정이에요.

잠깐 확인 — 칸이 5개인 리스트 s에서 s[1:3]에 3번 칸 값이 들어가나요?

안 들어가요. 끝 번호 3은 "3번 칸 바로 앞까지"라는 뜻이라 1번과 2번 칸 값만 나와요.
