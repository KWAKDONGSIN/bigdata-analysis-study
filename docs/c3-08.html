이 장 3줄 요약
  • CPU는 복잡한 일을 순차적으로, GPU는 단순한 일을 병렬로 잘해서 행렬 계산이 많은 딥러닝에는 GPU가 유리해요.
  • device = 'cuda' if torch.cuda.is_available() else 'cpu'로 장치를 고르고, x = x.to(device)처럼 반드시 다시 저장해요. 모델과 입력은 같은 device에 있어야 해요.
  • GPU Tensor는 .to('cpu').numpy()로 NumPy로 바꾸고, GPU가 없으면 Colab에서 런타임 → 런타임 유형 변경 → T4 GPU → 저장으로 켜요.
