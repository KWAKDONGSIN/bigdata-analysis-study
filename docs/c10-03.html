3단계. for 반복 — 바퀴 표를 그려요

for는 같은 일을 여러 번 시키는 문장이에요. 시료 3개를 하나씩 같은 방법으로 처리하는 실험과 같아요. 들여쓰기(앞쪽 공백)로 한 줄 안쪽으로 들어간 줄들이 한 바퀴마다 반복되고, 들여쓰기가 끝난 줄은 반복이 다 끝난 뒤 한 번만 실행돼요.

  • for i in range(3)은 i가 0, 1, 2로 바뀌며 세 바퀴를 돌아요. range(n)은 0부터 n-1까지예요(슬라이싱처럼 끝 숫자는 빠져요). range(1, 4)는 1, 2, 3이에요.
  • for n in [2, 4, 6]은 리스트의 값을 앞에서부터 하나씩 n에 넣으며 세 바퀴 돌아요.
  • 리스트.append(값)은 리스트 맨 끝에 값을 덧붙여요.

따라가는 법은 바퀴마다 한 행을 적는 거예요. 왜냐하면 반복문의 결과는 "몇 바퀴째에 변수가 어떻게 바뀌나"로만 정해지기 때문이에요.

① 풀이 예시 — 같이 따라가요

total = 0 for i in range(3): total = total + i print(i, total) print("끝", total)

print가 들여쓰기 안쪽에 있어서 바퀴마다 한 번씩 세 번 찍히고, 바깥쪽 print는 마지막에 한 번만 찍혀요. print가 안쪽이냐 바깥쪽이냐에 따라 결과 줄 수가 달라져요.

result = [] for n in [2, 4, 6]: result.append(n + 1) print(result)

③ 혼자 풀기 — 바퀴 표(k, 계산, s)를 그려서 풀어 보세요. range(1, 4)가 어떤 숫자를 만드는지부터 적으세요.

s = 0 for k in range(1, 4): s = s + k * 2 print(s)
답 보기
12

k는 1, 2, 3이에요. s는 0에서 시작해 1바퀴 0+1×2=2, 2바퀴 2+2×2=6, 3바퀴 6+3×2=12가 돼요. print는 들여쓰기 밖에 있어서 마지막에 한 번만 찍혀요.

시험엔 이렇게 써요 — 이렇게 고르세요

for가 나오면 먼저 "몇 바퀴, 각 바퀴에서 변수 값은?"을 적어요. 그다음 들여쓴 줄을 바퀴마다 한 번씩 실행해 바퀴 표를 채워요. print의 들여쓰기 위치를 꼭 확인하세요.

잠깐 확인 — range(5)가 만드는 숫자는 무엇인가요?

0, 1, 2, 3, 4예요. 모두 5개이고 끝 숫자 5는 들어가지 않아요.
