숫자, 글자(문자열), 계산, 참과 거짓

코드에 나오는 값은 크게 세 종류예요. 숫자, 글자, 참/거짓이에요.

종류모양 예시설명
정수7, -3소수점이 없는 숫자
실수3.5, 1.0소수점이 있는 숫자. 1.0처럼 .0이 붙으면 실수예요
문자열"Bori"따옴표로 감싼 글자. 따옴표가 없으면 변수 이름이에요
참/거짓True, False맞다/아니다. 첫 글자가 대문자예요

계산 기호는 아래와 같아요.

기호예결과와 설명
+ - *3 + 4, 6 * 2더하기, 빼기, 곱하기
/7 / 23.5 (나눗셈은 항상 소수까지 나와요)
**2 ** 38 (거듭제곱. 2의 3제곱)
== != >= <=5 == 5비교해서 True/False를 돌려줘요. 같은지 묻는 기호는 =가 두 개(==)예요

글자와 글자도 +로 이어 붙일 수 있고, len(...)은 길이를 세요. 글자 속에 변수 값을 끼워 넣고 싶을 때는 따옴표 앞에 f를 붙이고 { } 안에 변수를 써요. 이것을 f-string이라고 해요.

name = "Bori" print("Hi " + name) print(f"{name}가 멍멍 짖습니다.") print(len(name)) print(7 / 2, 2 ** 3) print(5 == 5, 3 >= 4) print(f"{3.14159:.2f}")
Hi Bori Bori가 멍멍 짖습니다. 4 3.5 8 True False 3.14
코드 줄무슨 뜻
"Hi " + name글자 이어 붙이기. 뒤에 공백이 있으니 "Hi Bori"
f"{name}가 멍멍 짖습니다."중괄호 자리에 name의 값(Bori)이 들어가요
len(name)글자 수 B-o-r-i = 4
f"{3.14159:.2f}":.2f는 "소수 둘째 자리까지"예요. 3.14가 찍혀요
시험엔 이렇게 써요 — 이렇게 고르세요

f-string은 "중괄호 자리를 변수 값으로 바꿔서 읽기"만 하면 끝이에요. /는 항상 소수가 나오고(7/2=3.5), ==는 같은지 묻는 기호라는 두 가지만 기억하세요.

잠깐 확인 — x = "Kim"일 때 print(f"{x}님")은 무엇을 찍나요?

Kim님이에요. 중괄호 자리에 x의 값이 들어가요.
