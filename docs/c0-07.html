조건 — if, elif, else와 한 줄 조건식

if는 "조건이 맞을 때만 실행해라"예요. 조건이 틀리면 elif(그게 아니고 이것이 맞으면), 모두 틀리면 else(나머지 전부) 줄이 실행돼요. 위에서부터 보다가 처음으로 맞는 하나만 실행하고 나머지는 건너뛰어요.

score = 85 if score >= 90: print("A") elif score >= 80: print("B") else: print("C")
B
코드 줄무슨 뜻
if score >= 90:85 >= 90은 False라서 아래 줄을 건너뛰어요
elif score >= 80:85 >= 80은 True라서 print("B") 실행. 그리고 if 묶음 전체가 끝나요
else:앞이 다 틀렸을 때만. 이번엔 실행 안 돼요

조건이 맞는지에 따라 값을 고르는 한 줄짜리 모양도 자주 나와요. 값1 if 조건 else 값2 형태이고 "조건이 맞으면 값1, 아니면 값2"예요. GPU 장에서 보는 'cuda' if torch.cuda.is_available() else 'cpu'가 바로 이 모양이에요.

cuda_ok = False device = 'cuda' if cuda_ok else 'cpu' print(device) print(max(0, 5 - 20), min(3, 9))
cpu 0 3

max(a, b)는 큰 쪽, min(a, b)는 작은 쪽을 돌려줘요. max(0, 5 - 20)은 5−20 = −15와 0 중 큰 쪽이라서 0이에요. "음수가 되면 0으로 막아 둔다"는 뜻으로 클래스 예제(자동차 속도)에 나와요.

시험엔 이렇게 써요 — 이렇게 고르세요

if-elif-else는 위에서부터 조건을 하나씩 확인하고 처음 True인 줄 하나만 실행해요. A if 조건 else B는 먼저 조건이 True인지 False인지 정한 뒤 A 또는 B를 골라요.

잠깐 확인 — x = 3일 때 'big' if x >= 5 else 'small'의 값은?

'small'이에요. 3 >= 5는 False라서 else 쪽 값을 골라요.
