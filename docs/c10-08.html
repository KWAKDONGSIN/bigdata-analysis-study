8단계. 학습 5줄 — zero_grad, forward, loss, backward, step

딥러닝 학습은 매 바퀴 같은 5줄을 반복해요. 순서와 역할을 외우면 대부분의 문제가 풀려요.

순서코드하는 일 (한 줄)
1optimizer.zero_grad()지난 바퀴에 쌓인 기울기(grad)를 지워요
2prediction = model(x)예측값을 계산해요 (forward)
3loss = criterion(prediction, y)예측과 정답의 차이를 숫자 하나(loss)로 만들어요
4loss.backward()기울기를 계산해 .grad에 저장만 해요. 파라미터 값은 안 바뀌어요
5optimizer.step()저장된 기울기로 파라미터 값을 실제로 고쳐요
외우기 팁

"비우고 → 예측하고 → 재고 → 기울기 구하고 → 한 걸음". 값이 바뀌는 건 마지막 step 한 줄뿐이에요. 기울기는 w - lr × grad로 w를 고치는 재료일 뿐이에요.

아래 예시는 모델 없이 값 하나(w)만 키워서 5줄이 실제로 숫자를 어떻게 바꾸는지 눈으로 보는 거예요. loss는 (w - 5)²이라서 w가 5에 가까울수록 작아요. 이때 기울기는 2 × (w - 5)이고, 계산은 컴퓨터가 해 주니 표에서는 값만 받아 적으세요. 학습률 lr은 한 걸음 크기예요.

① 풀이 예시 — 같이 따라가요

import torch w = torch.tensor(1.0, requires_grad=True) optimizer = torch.optim.SGD([w], lr=0.25) for step in range(3): optimizer.zero_grad() loss = (w - 5) ** 2 loss.backward() optimizer.step() print(step, w.grad.item(), w.item())

② 빈칸 풀이 — 가려진 칸을 직접 채워 보세요

w = torch.tensor(0.0, requires_grad=True) optimizer = torch.optim.SGD([w], lr=0.25) for step in range(3): optimizer.zero_grad() loss = (w - 2) ** 2 loss.backward() optimizer.step() print(step, w.grad.item(), w.item())

③ 혼자 풀기 — 첫 예시와 똑같은데 optimizer.zero_grad() 줄이 빠졌어요. 기울기를 지우지 않으면 새 기울기가 이전 값에 더해져서 쌓여요. 두 줄을 적어 보세요.

w = torch.tensor(1.0, requires_grad=True) optimizer = torch.optim.SGD([w], lr=0.25) for step in range(2): loss = (w - 5) ** 2 loss.backward() optimizer.step() print(w.grad.item(), w.item())
답 보기
-8.0 3.0 -12.0 6.0

0바퀴는 처음이라 grad가 -8.0이고 w = 1 - 0.25×(-8) = 3.0이에요. 1바퀴에서 새 기울기는 2×(3-5) = -4인데, 지우지 않아서 이전 -8에 더해져 grad가 -12.0이 돼요. 그래서 w = 3 - 0.25×(-12) = 6.0이 되어 5를 지나쳐 버려요. zero_grad가 필요한 이유가 이거예요.

시험엔 이렇게 써요 — 이렇게 고르세요

학습 5줄 문제는 이렇게 답하세요. loss.backward()는 기울기를 계산해 저장만 하고 파라미터 값은 바꾸지 않는다. optimizer.step()은 저장된 기울기로 옵티마이저에 전달된 파라미터를 갱신한다. optimizer.zero_grad()는 쌓인 기울기를 지우는 것이지 파라미터 값을 0으로 만드는 게 아니다. 샘플 5번의 정답이 이 문장이에요.

잠깐 확인 — loss.backward()를 부르면 w의 값이 바뀌나요?

안 바뀌어요. backward는 기울기를 계산해 w.grad에 저장만 해요. 값을 바꾸는 건 optimizer.step()이에요.
