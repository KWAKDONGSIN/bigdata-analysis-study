5단계. 텐서 shape 읽기 — 숫자 하나는 줄이고, 범위는 남겨요

텐서(Tensor)는 숫자를 격자 모양으로 담은 상자예요. shape는 방향마다 칸이 몇 개인지를 적은 거예요. (2, 3)은 2줄 × 3칸이고, 시료 트레이가 2줄에 3칸씩 있는 모양이에요. shape의 숫자를 모두 곱하면 숫자 전체 개수예요(2×3=6).

  • torch.arange(6)은 0, 1, 2, 3, 4, 5를 만들어요(range처럼 끝 숫자는 빠져요).
  • .reshape(2, 3)은 같은 숫자들을 새 모양으로 다시 채워요. 곱이 같아야 해요. 숫자 하나 자리에 -1을 쓰면 "나머지는 알아서 계산해"라는 뜻이에요.
  • 텐서 번호도 0부터예요. x[:, 1]은 "모든 줄(:)에서 1번 칸"이에요.
외우기 팁 — 가장 중요한 규칙

번호를 숫자 하나로 뽑으면(x[:, 1]) 그 방향 칸이 사라져요. 번호를 범위로 뽑으면(x[:, 1:2]) 그 방향 칸이 1개짜리로 남아요. 이 한 쌍이 시험 1번이에요.

① 풀이 예시 — 같이 따라가요

import torch x = torch.arange(6).reshape(2, 3) print(x) print(tuple(x.shape)) print(x[:, 1]) print(tuple(x[:, 1].shape)) print(tuple(x[:, 1:2].shape))

x는 이런 모양이에요. 줄 번호는 0, 1이고 칸 번호는 0, 1, 2예요.

y는 3줄 × 4칸이에요.

③ 혼자 풀기 — 3차원이에요. shape 숫자 세 개를 (층, 줄, 칸)이라고 읽고, 각 줄에서 사라지는 방향과 남는 방향을 적어 보세요.

z = torch.arange(24).reshape(2, 3, 4) print(tuple(z.shape)) print(tuple(z[0].shape)) print(tuple(z[:, 1, :].shape)) print(tuple(z[:, :, 0:1].shape))
답 보기
(2, 3, 4) (3, 4) (2, 4) (2, 3, 1)

z[0]은 층을 숫자 하나로 뽑아 층 방향이 사라져서 (3, 4)예요. z[:, 1, :]은 가운데(줄) 방향만 숫자 하나로 뽑아서 사라지니 (2, 4)예요. z[:, :, 0:1]은 칸 방향을 범위로 뽑아 1개짜리로 남아서 (2, 3, 1)이에요.

시험엔 이렇게 써요 — 이렇게 고르세요

shape 문제는 순서대로 푸세요. ① 원래 shape를 적는다. ② 대괄호 안을 방향마다 읽어, 숫자 하나면 그 방향을 지우고 범위(a:b)나 :면 남긴다. ③ 남은 숫자를 순서대로 적는다. 예를 들어 (3, 4)에서 [:, 1]은 (3,), [:, 1:2]는 (3, 1)이에요.

잠깐 확인 — 12개짜리를 reshape(5, -1)로 바꿀 수 있나요?

안 돼요(에러). 12를 5로 나누어떨어지지 않아서 한 줄에 몇 칸이 되는지 정할 수 없어요. 곱이 원래 개수와 같아야 해요.
