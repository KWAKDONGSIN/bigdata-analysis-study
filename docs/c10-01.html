1단계. print와 변수 — 이름표 상자 값 따라가기

비유 — 실험 노트에 값 적기

시료를 희석할 때마다 노트에 "지금 농도 얼마"를 한 줄씩 고쳐 적잖아요. 코드 따라가기도 똑같아요. 줄이 실행될 때마다 변수 값이 어떻게 바뀌는지 메모장 표에 한 줄씩 적으면, 마지막에 답이 저절로 나와요.

코드 읽기 3원칙
  • 위에서 아래로, 한 줄씩. 컴퓨터는 적힌 순서대로만 일해요. 건너뛰거나 미리 알아맞히지 않아요.
  • 오른쪽을 먼저 계산하고, 그 결과를 왼쪽 이름에 저장해요. x = 3 + 4는 "3+4를 계산해서 7을 x라는 이름표 상자에 넣어라"예요. 수학의 "같다"가 아니에요.
  • print가 찍은 것만 화면에 나와요. 시험의 "실행 결과는?"은 print가 찍는 글자를 순서대로 맞히는 문제예요.
이 장을 쓰는 법 — 점점 풀이를 지워 가요

각 단계는 세 칸이에요. ① 풀이 예시는 표가 다 채워져 있으니 눈으로 따라가세요. ② 빈칸 풀이는 표의 몇 칸이 ?로 가려져 있어요. 직접 계산해 본 뒤 눌러서 확인하세요. ③ 혼자 풀기는 표 없이 종이에 직접 표를 그려 풀고 답을 열어 보세요.

왜 이렇게 하냐면, 처음부터 혼자 풀면 막막하고 풀이만 읽으면 눈에만 익고 손에는 안 남기 때문이에요. 완성된 풀이를 보고, 빈칸을 채우고, 마지막에 혼자 하는 순서가 처음 배우는 사람에게 가장 잘 남아요.

변수(variable)는 값을 담는 상자에 이름표를 붙인 거예요. a = 5는 "a 상자에 5를 넣어라"예요. 상자에는 한 번에 값 하나만 들어가서, 새 값을 넣으면 예전 값은 사라져요.

f"..."는 따옴표 안의 {이름} 자리에 그 변수의 값을 끼워 넣어 주는 문자열이에요. 읽을 때는 중괄호 안을 값으로 바꾸기만 하면 돼요.

① 풀이 예시 — 같이 따라가요

a = 5 b = a + 2 a = 10 print(a, b) print(b * 2) print(f"b는 {b}")

변수마다 열을 하나씩 만들고, 줄이 실행될 때마다 바뀐 값을 적어요. 이게 메모장 표예요.

줄하는 일ab화면에 나온 것
1a = 5 → a에 5 저장5-
2b = a + 2 → 5+2=7을 b에 저장57
3a = 10 → a만 새 값으로 바뀜107 (그대로)
4print(a, b)10710 7
5print(b * 2) → 7×210714
6print(f"b는 {b}") → {b}를 7로107b는 7
10 7 14 b는 7

3번 줄에서 a가 바뀌어도 b는 7 그대로예요. b를 만들 때 그 순간 계산된 값 7이 들어갔을 뿐, a와 계속 이어져 있는 게 아니기 때문이에요. 초보자가 가장 많이 틀리는 곳이에요.

③ 혼자 풀기 — 종이에 name, n 열이 있는 표를 그리고 화면에 나오는 두 줄을 적어 보세요.

name = "Bori" n = 2 n = n * n print(name, n) print(f"{name}는 {n}살")
답 보기
Bori 4 Bori는 4살

name은 계속 "Bori"예요. n은 2로 시작해 n = n * n에서 2×2=4가 되어 다시 n에 저장돼요. 두 print 모두 n이 4일 때 실행돼요.

시험엔 이렇게 써요 — 이렇게 고르세요

변수마다 열을 하나 만들고, 줄을 실행할 때마다 그 줄에서 바뀐 칸만 고쳐 적어요. 선택지를 먼저 보지 말고 표를 끝까지 채운 다음에 맞는 것을 고르세요. 답은 "print가 찍은 것"뿐이에요.

잠깐 확인 — a = 1 다음 줄에 a = a + 1이 있으면 a는 얼마인가요?

2예요. 오른쪽을 먼저 계산해(1+1=2) 그 값을 다시 a 상자에 넣어요. 예전 값 1은 사라져요.
