PyTorch 모델의 부모 클래스예요. 이걸 상속하고 __init__과 forward만 만들면 학습에 필요한 나머지 기능은 알아서 붙어요.

autogradAutograd

requires_gradrequires_grad
이 텐서의 gradient를 계산·기록해 달라는 표시예요. True여야 backward 후에 .grad가 생겨요.
backwardBackward / Backpropagation

계산 그래프Computational graph
계산 과정을 점과 선으로 기록한 지도예요. backward가 이 지도를 거꾸로 따라가며 gradient를 구해요. 한 번 쓰면 풀려서 재사용할 수 없어요.
leaf tensorLeaf tensor
계산 그래프의 맨 끝에 있는 텐서예요. 직접 만든 requires_grad 텐서와 모델의 weight, bias가 해당돼요. .grad는 leaf에만 저장돼요.
.grad.grad
backward 후 leaf 텐서에 저장되는 gradient 값이에요. backward 전에는 None이에요.
gradient 누적Gradient accumulation
backward를 부를 때마다 .grad에 덮어쓰지 않고 더해져요. 그래서 매 step 시작에 0으로 지워야 해요.
zero_gradzero_grad()
쌓인 gradient를 지워요. optimizer.zero_grad()는 학습 step의 첫 단계예요. backward보다 앞에 불러야 해요.
torch.no_gradtorch.no_grad()
이 블록 안에서는 gradient를 기록하지 않아요. weight를 직접 고칠 때, 평가·예측할 때 써서 계산을 아껴요.
in-place 연산In-place operation
새로 만들지 않고 원래 텐서의 값을 그 자리에서 고치는 연산이에요. W -= lr * W.grad가 예예요. requires_grad 텐서에는 no_grad 안에서만 할 수 있어요.
detachdetach()
계산 그래프와의 연결을 끊은 텐서를 만들어요. 값만 보고 싶을 때 써요.
경사 하강법Gradient descent
loss가 줄어드는 방향으로 weight를 조금씩 옮기는 방법이에요. 산에서 가장 낮은 곳을 향해 한 발씩 내려가는 것과 같아요.
학습률Learning rate
한 번에 weight를 얼마나 움직일지 정하는 숫자예요. 너무 크면 튀어서 못 찾고, 너무 작으면 느려요. 보통 아주 작게 써요.
업데이트 식Update rule
새 w = 현재 w − lr × grad예요. gradient가 음수면 w가 커지고, 양수면 줄어요.
lossLoss
예측이 정답에서 얼마나 틀렸는지를 숫자 하나로 요약한 값이에요. 작을수록 잘 맞는 거예요.
predictionPrediction
모델이 내놓은 답이에요. 정답(target)과 비교해서 loss를 구해요.
targetTarget
모델이 맞혀야 하는 정답이에요. 예측할 때는 넣지 않고 loss 계산에만 써요.
MSEMean Squared Error
(예측 − 정답)을 제곱해서 평균 낸 값이에요. 제곱해서 +와 −가 서로 지워지지 않아요. 예 [3,4] vs [1,5]는 2.5예요.
nn.MSELosstorch.nn.MSELoss
MSE를 대신 계산해 주는 도구예요. criterion = nn.MSELoss()로 만들고 criterion(prediction, target)으로 써요. 결과는 숫자 하나예요.
CrossEntropyLossCross entropy loss
분류 문제에서 많이 쓰는 loss예요. 수업에서는 이름만 소개했어요.
optimizerOptimizer
gradient를 보고 weight를 실제로 고치는 도구예요. model.parameters()를 넘겨 만들고, step()을 불러야 고쳐져요.
SGDStochastic Gradient Descent
가장 기본적인 optimizer예요. w ← w − lr × grad로 고쳐요. optim.SGD(model.parameters(), lr=0.1)로 만들어요.
AdamAdam
SGD보다 똑똑하게 방향과 속도를 조절하는 optimizer예요. 수업에서는 이름만 나왔어요.
stepstep()
저장된 gradient로 weight를 한 번 고치는 함수예요. gradient를 새로 계산하지는 않아요.
학습 5단계Training step
zero_grad → forward → loss → backward → step의 다섯 단계예요. batch마다 이 순서로 한 번씩 해요.
회귀Regression
점수나 가격처럼 이어지는 숫자를 맞히는 문제예요. 주로 MSE loss를 써요.
분류Classification
합격/불합격, 고양이/강아지처럼 종류를 고르는 문제예요.
범주형 데이터Categorical data
성별처럼 글자로 된 종류 데이터예요. 모델은 숫자만 다루니까 남=0, 여=1로 바꾸거나 one-hot으로 바꿔요.
sampleSample
입력 하나와 그에 맞는 정답 하나의 짝이에요. 학생 한 명의 정보와 그 학생의 점수가 샘플 하나예요.
batchBatch
한 번에 묶어서 처리하는 샘플 묶음이에요. 샘플 4개씩 묶으면 batch 크기가 4예요.
batch_sizeBatch size
한 batch에 들어가는 샘플 수예요. 10개를 4개씩 자르면 4, 4, 2로 세 묶음이 돼요.
epochEpoch
학습 데이터 전체를 한 번 모두 사용한 것이에요. 책 한 권을 처음부터 끝까지 한 번 읽은 것과 같아요.
iterationIteration / Step
batch 하나로 weight를 한 번 고치는 일이에요. 1 epoch 동안 iteration 수는 batch 개수와 같아요.
DatasetDataset
샘플을 번호로 꺼낼 수 있는 데이터 모음이에요. __len__과 __getitem__을 만들어 주면 돼요.
__len____len__
len(dataset)을 하면 불려서 샘플이 모두 몇 개인지 알려주는 메서드예요.
__getitem____getitem__
dataset[3]처럼 번호로 꺼낼 때 불려서 3번째 (입력, 정답) 쌍을 돌려주는 메서드예요.
TensorDatasetTensorDataset
입력 텐서와 정답 텐서를 같은 번호끼리 짝지어 주는 PyTorch의 기본 Dataset이에요. 샘플 수(첫 차원)가 같아야 해요.
DataLoaderDataLoader
Dataset에서 샘플을 꺼내 batch로 묶어 차례로 내주는 도구예요. for batch_x, batch_y in loader:로 돌아요.
shuffleShuffle
epoch마다 데이터 순서를 섞는 옵션이에요. 학습 때는 True, 검증 때는 False로 해요.
drop_lastdrop_last
batch_size보다 적게 남은 마지막 묶음을 버릴지 정하는 옵션이에요. 기본값은 False라서 남은 것도 써요.
len(loader)len(DataLoader)
한 epoch에 batch가 몇 묶음인지 알려 줘요. 샘플 수 ÷ batch 크기를 올림한 값이에요. 10개, batch 4면 3이에요.
train setTraining set
모델이 보고 배우는 데이터예요. 이걸로 weight를 고쳐요.
validation setValidation set
학습에 쓰지 않고 따로 떼어 둔 데이터예요. 처음 보는 데이터에서 얼마나 잘하는지 재는 시험지 역할이에요.
test setTest set
마지막에 최종 성능을 재는 데이터예요. 학습에도, 중간 점검에도 쓰지 않아요.
model.train()model.train()
모델을 학습용 모드로 바꿔요. Dropout 같은 층이 학습 때 방식으로 일해요.
model.eval()model.eval()
모델을 평가용 모드로 바꿔요. gradient를 끄지는 않아서 torch.no_grad()를 따로 함께 써요.
과적합Overfitting
학습 데이터는 잘 맞히는데 처음 보는 데이터에서는 못 맞히는 상태예요. 문제집 답만 외운 것과 같아요. validation으로 확인해요.
epoch lossEpoch loss
한 epoch의 전체 평균 loss예요. batch loss × batch 샘플 수를 모두 더한 뒤 전체 샘플 수로 나눠요.
딥러닝Deep learning
층을 여러 겹 쌓은 인공신경망으로 데이터에서 규칙을 스스로 배우게 하는 방법이에요.
인공신경망Neural network
숫자를 받아 곱하고 더하는 층을 여러 겹 쌓은 계산 구조예요. 층의 weight를 학습으로 고쳐요.
학습Training
데이터를 보며 loss가 줄어들도록 weight를 반복해서 고치는 일이에요.
추론Inference
학습이 끝난 모델로 새 입력의 답을 계산하는 일이에요. 이때는 weight를 고치지 않아요.
파라미터 초기화Initialization
학습 시작 때 weight를 randn 같은 랜덤 값으로 채우는 거예요. 그래서 처음 예측은 틀리는 게 정상이에요.
수렴Convergence
학습을 거듭하면서 loss가 더는 줄지 않을 만큼 작은 값에 가까워지는 거예요. w가 정답 2에 가까워지는 모습이에요.
