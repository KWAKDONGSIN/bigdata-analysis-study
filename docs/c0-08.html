import와 점(.) 표기 — 도구 상자에서 도구 꺼내기 ★★

파이썬에는 남들이 만들어 둔 도구 상자(라이브러리, 또는 모듈)가 많아요. 쓰려면 먼저 import로 상자를 가져와요. 딥러닝 도구 상자의 이름이 torch(파이토치)예요.

상자 안의 도구를 꺼낼 때는 점(.)을 써요. 점은 "~ 안의"라고 읽으면 돼요. torch.arange는 "torch 안의 arange"예요.

코드읽는 법
import torchtorch 상자를 가져와요. 이제 torch.도구이름으로 써요
import numpy as npnumpy 상자를 가져오되 "np"라는 짧은 별명으로 불러요
import torch.nn as nntorch 안의 nn 칸을 "nn"이라는 별명으로 가져와요
from torch import nn위와 같은 효과예요. torch에서 nn만 꺼내 와요
from torch.utils.data import TensorDataset, DataLoadertorch.utils.data 칸에서 두 가지(TensorDataset, DataLoader)를 꺼내 와요

점은 두 가지 뜻으로 쓰여요. 괄호가 있느냐 없느냐가 차이예요.

모양뜻예
대상.이름 (괄호 없음)대상이 가진 정보(속성)를 읽어요x.shape, x.dtype, self.name
대상.이름(...) (괄호 있음)대상에게 동작을 시켜요(메서드 호출)x.reshape(3, 4), a.append(60)

괄호 종류도 헷갈리기 쉬워요. ( )는 함수 호출이나 계산 묶음, [ ]는 리스트와 번호 매기기(인덱스), { }는 f-string에서 값이 들어갈 자리(그리고 딕셔너리)를 뜻해요. {"loss": 0.5}처럼 이름표와 값 쌍을 묶은 것을 딕셔너리라고 하고, d["loss"]로 꺼내요.

시험엔 이렇게 써요 — 이렇게 고르세요

import 줄은 "도구를 가져오는 준비 단계"라서 결과에는 영향이 없어요. 그 아래에서 torch.이나 nn.으로 시작하는 줄이 진짜 일을 해요. 점 뒤에 괄호가 있으면 동작, 없으면 정보 읽기라고 구분하세요.

잠깐 확인 — x.shape와 x.sum() 중 괄호가 필요한 것은?

x.sum()이에요. shape는 x가 가진 정보를 읽을 뿐이라 괄호가 없고, sum은 합을 구하라는 동작이라 괄호가 있어요.
