6단계. nn.Linear(in, out) — 출력 shape와 파라미터 수

nn.Linear(3, 2)는 "입력 숫자 3개를 받아 출력 숫자 2개를 내놓는 계산기 한 층"이에요. 재료 3가지를 넣으면 점수 2개가 나오는 계산기를 떠올리면 돼요. 괄호 안 순서는 (입력 개수 in, 출력 개수 out)이에요.

  • 입력 shape는 (샘플 수, in)이어야 하고 출력 shape는 (샘플 수, out)이에요. 샘플 수 칸은 그대로 두고 마지막 칸만 in에서 out으로 바뀐다고 읽으세요.
  • 이 층이 학습으로 고치는 값(파라미터)은 두 가지예요. weight의 shape는 (out, in)이고 bias의 shape는 (out,)예요.
  • 파라미터 개수는 in × out + out이에요. weight 칸 수 in×out에 bias 칸 수 out을 더한 거예요.

sum(p.numel() for p in fc.parameters())는 길어 보이지만 "이 층의 모든 파라미터 숫자 개수의 합"이라고만 읽으세요. 문법을 풀어 쓸 필요는 없어요.

① 풀이 예시 — 같이 따라가요

import torch from torch import nn fc = nn.Linear(3, 2) x = torch.ones(4, 3) y = fc(x) print(tuple(y.shape)) print(tuple(fc.weight.shape), tuple(fc.bias.shape)) print(sum(p.numel() for p in fc.parameters()))
코드따라가기화면에 나온 것
fc = nn.Linear(3, 2)in=3, out=2인 층을 만듦
x = torch.ones(4, 3)1로 가득한 4줄 × 3칸. 샘플 4개, 샘플마다 숫자 3개
y = fc(x)(4, 3)에서 마지막 칸 3이 2로 바뀜 → (4, 2)
print(tuple(y.shape))샘플 수 4는 그대로, 마지막은 out=2(4, 2)
fc.weight.shape, fc.bias.shapeweight는 (out, in) = (2, 3), bias는 (out,) = (2,)(2, 3) (2,)
sum(... numel ...)weight 2×3 = 6개 + bias 2개8
(4, 2) (2, 3) (2,) 8

입력의 마지막 칸이 in과 다르면 에러가 나요. 예를 들어 torch.ones(4, 5)를 이 층에 넣으면 RuntimeError: mat1 and mat2 shapes cannot be multiplied (4x5 and 3x2)라는 에러가 떠요. 층은 숫자 3개짜리 입력만 받도록 만들어졌기 때문이에요.

② 빈칸 풀이 — 가려진 칸을 직접 채워 보세요

fc = nn.Linear(5, 3) x = torch.ones(10, 5) print(tuple(fc.weight.shape)) print(tuple(fc(x).shape)) print(sum(p.numel() for p in fc.parameters()))

파라미터 개수weight 5×3 + bias 3 =

③ 혼자 풀기 — 층이 두 개예요(ReLU는 파라미터가 없고 모양도 안 바꿔요). 층마다 shape를 이어서 따라가고 파라미터를 층별로 더해 보세요.

net = nn.Sequential(nn.Linear(4, 8), nn.ReLU(), nn.Linear(8, 1)) x = torch.ones(2, 4) print(tuple(net(x).shape)) print(sum(p.numel() for p in net.parameters()))
답 보기
(2, 1) 49

shape는 (2, 4) → 첫 Linear(4, 8)을 지나 (2, 8) → ReLU를 지나도 (2, 8) → Linear(8, 1)을 지나 (2, 1)이에요. 파라미터는 첫 층 4×8+8 = 40, 둘째 층 8×1+1 = 9로 합해서 49예요.

시험엔 이렇게 써요 — 이렇게 고르세요

Linear(in, out)이 보이면 세 가지만 하세요. ① 입력의 마지막 칸이 in인지 확인. ② 출력은 마지막 칸만 out으로. ③ 파라미터 개수는 in×out+out. 층이 여러 개면 앞 층의 out이 다음 층의 in과 같아야 이어져요.

잠깐 확인 — nn.Linear(4, 2)에 (7, 4) 텐서를 넣으면 출력 shape는?

(7, 2)예요. 샘플 수 7은 그대로이고 마지막 칸 4가 out인 2로 바뀌어요.
